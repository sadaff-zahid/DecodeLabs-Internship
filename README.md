# StudyPlanner

DecodeLabs Full Stack Development, Project 1: Responsive Frontend Interface.

A simple study task planner built with plain HTML, CSS and JavaScript (no frameworks).

## What it does
- Add a task with a subject and due date
- Mark tasks as done, or delete them
- Filter by All, Pending or Done
- Shows a progress bar
- Saves your tasks in the browser (localStorage)

## How it follows the project brief
- Mobile first: one column on phones, two columns from 768px, wider layout from 1024px
- Semantic HTML5: header, nav, main, aside, article, footer
- CSS Grid for the page layout, Flexbox for small parts, a container query for task cards
- clamp() for headings that scale with the screen
- Palette: Mocha Mousse, Ethereal Blue, Moonlit Grey
- Fonts: Montserrat (headings) and Open Sans (text), 3 weights in total
- Accessible: labels on inputs, keyboard focus styles, skip link, big tap targets

## Run it
Open `index.html` in your browser.

## Files
- `index.html` the page structure
- `style.css` the design and layout
- `script.js` the app logic
